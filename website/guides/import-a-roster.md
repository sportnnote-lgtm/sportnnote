Typing in a whole year group one by one takes too long. Export the list from your school system (SIMS, Arbor, iSAMS, PowerSchool or any other) or a spreadsheet as CSV. Then paste it in or pick the file, check the preview, and import.

## Before you start
- For a school, you're an admin of its community. For a team, you're its captain, vice-captain or a team admin.
- A club team's squad is picked from the club's members, so import the students into the school first.

## Step by step
1. School: open the community → **Members** tab → **📥 Import CSV**. Team: open the team's squad → **📥 Import squad from CSV**.
2. On the web, tap **Choose CSV file**, or paste the rows, including the header row. Tap **Template** for a ready-made example.
3. Columns can be in any order: Name (or First name and Last name), Date of birth, Gender, Class or Year, House, Team, Jersey, Guardian name, Guardian email and Guardian phone. Common school-system headers such as "Legal Surname", "Reg Group" or "Primary Contact Email" are recognised.
4. Check the **Preview**. Each row shows what will happen: **New**, **Already here — skipped**, or why it can't be read, such as an impossible date or a bad email.
5. If the app says every date fits both ways, choose **Day first** or **Month first**.
6. Tap **Import N people**.

## What gets saved
- Each new person gets a profile with their date of birth and gender. For a school, they're also added as a member with their class and House from today.
- Phone numbers become full international numbers, like +44 7400 123456. A local number is read for your region.
- Contact details are always the **guardian's**. A child never gets their own phone or email from an import.

> **Important:** Guardian contacts are private. Only the guardian, the school's admins and coaches can see them.

## Duplicates
- A row with the same name and date of birth as someone already there is skipped. So is a row with the same first name and guardian email.
- A repeat inside the file is imported once.
- For a squad, someone already at the school is added to the squad, not created again.
- Turn on **Add look-alikes as new people** only for different people who share a name.

## Common questions
### My file is an Excel workbook.
Save it as CSV first (File → Save as → CSV), or copy the cells and paste them in.

### Dates came out wrong.
US-style files are read month first and others day first. A date such as 25/03 tells the app which order the file uses. Check the spelled-out dates in the preview before importing.
