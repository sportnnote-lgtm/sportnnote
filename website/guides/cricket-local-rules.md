School and gully matches often use their own rules. A wide is worth 2 runs, a no-ball counts as one of the six balls, or there are no byes on a short pitch. You can set these rules for one match before the first ball, or change them during play when the umpires agree. A change during play applies from the next ball, and balls already bowled keep the rules they were bowled under.

## Before you start
- Before ball 1, the match scorer or a match host can set the rules.
- Once play has started, only the scorer can change them. Everyone else sees the rules but can't edit them, with the note "Only the scorer can change rules during play."
- The rules are for this match only. They don't change the format for the rest of a tournament.

## The rules you can set

- **Runs for a wide**: penalty runs for each wide, 0 to 5. Standard is 1.
- **Wide counts as a ball**: a wide uses up one of the over's balls. Standard is off. It still isn't a ball faced by the batter.
- **Runs for a no-ball**: penalty runs for each no-ball, 0 to 5. Standard is 1.
- **No-ball counts as a ball**: a no-ball uses up one of the over's balls. Standard is off.
- **Free hit after a no-ball**: the next ball is a free hit. Standard is on.
- **Normal wide/no-ball rules in the last N overs**: the four wide and no-ball settings go back to standard for the last N overs of each innings. Standard is 0, which means never.
- **Byes allowed** and **Leg byes allowed**: show or hide the **Bye** and **Leg bye** buttons. Standard is on.

## Step by step: before the match
1. Open the match and go to the **Info** tab.
2. Find the **Match rules** card. The pill next to the title reads **Standard**, or "2 custom" if you've changed two settings.
3. Tap the values you want, for example **2** under **Runs for a wide**, and **On** under **No-ball counts as a ball**.
4. Tap **Apply**. Until the first ball is bowled, these settings become the match's own rules (the toss and picking players don't count as play).

You can also set the same rules when you create the match: tap **⚙ Customize this format** in the format section.

## Step by step: during the match
1. On the **Scoring** tab, tap **☰ Quick options** at the bottom.
2. Tap the **Match settings** tile. The **Match rules** card opens inside the sheet. It's also on the **Info** tab.
3. Change the settings you need.
4. Tap **Apply from next ball**. You'll see "New rules apply from the next ball".

A **RULES** line appears in the ball-by-ball timeline for everyone following the match, for example "Wide 2 runs · counts as a ball".

> **Tip:** Changed something by mistake? Tap **Reset to standard** to fill the card with the standard values, then tap **Apply from next ball** again. Nothing changes until you tap Apply.

## How you know local rules are on
- A chip above the run pad shows the rules in force, for example "Local rules: Wd 2 · NB = ball · no byes".
- In the last overs, if you set **Normal wide/no-ball rules in the last N overs**, the chip changes to "Normal rules now (last 2 overs)".
- The **Wide** and **No ball** prompts show the value in force, for example "Wide (+2)", and the buttons show the total, for example **Wd+1 (=3)**.

> **Note:** A Super Over is always played to standard rules, whatever you set for the match. This follows normal tie-breaker practice.

## Common questions
### Will changing the wide value rewrite the wides already bowled?
No. Every ball keeps the rule it was bowled under. Only balls from now on use the new value. That's why a change during play is saved as its own entry in the match, not as an edit to the format.

### Can I undo a rules change?
Yes. A rules change is one entry like a ball, so **↶ Undo** takes it back if it was the last thing you entered.

### Does "last N overs" also bring back byes and free hits?
No. It only resets the four wide and no-ball settings: the runs for each, and whether each counts as a ball. Byes, leg byes and the free hit stay as you set them.

### Can I change the number of overs here?
No. Use **⏱ Overs & target** on the Scoring tab. See [Rain, fewer overs and DLS targets](/guides/cricket-rain-and-dls/).

### What happens to byes I already entered if I switch byes off?
They stay. Switching off byes only hides the **Bye** button from the next ball on. It also removes Byes from the options when you record a run out.
