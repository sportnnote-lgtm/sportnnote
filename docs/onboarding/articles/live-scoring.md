# Live scoring

*Full Help-centre guide. Covers KB topics: `set-lineup-squad`, `choose-format`,
`undo-fix-mistake`, `offline-scoring`, `rain-dls`.*

Scoring is the heart of Sportfolio. The controls change per sport, but the rhythm
is always the same: **start → tap as it happens → fix if needed → done.**

## Set the playing XI / squad

Before a match, tell Sportfolio who's actually playing so stats attach to the
right people.

1. Open the match and go to the **Squad / Lineup** step (shown before you start,
   and reachable from the match menu).
2. For each team, tap players to add them to the playing lineup.
3. Use **Fill** to add the whole team roster at once, then remove anyone who's
   sitting out.
4. Use **Copy last match's XI** to reuse the same lineup from this team's previous
   match — handy for a squad that plays together often.
5. Missing a player? Tap **+ Add player** to create them without leaving the
   screen (see *Add players to a team* below).

You can start scoring without a full lineup and add players later, but setting it
up front means you can pick the scorer/goal-scorer straight from the list.

## Choose a format

The **format** sets the rules — how many players a side, how long, how many
overs/periods — so scoring behaves correctly.

- When you create a match or tournament, pick a **preset** for the sport:
  - **Cricket:** T20, ODI, T10, The Hundred, Sixes, Box, Test
  - **Football:** 11-a-side, 7s, 5-a-side turf, Futsal
  - **Basketball:** 5v5, 3×3, 2v2, 1v1
  - …and equivalents for the other sports.
- Tap **⚙ Customize this format** to set individual rules yourself — players per
  side, overs, periods, and sport-specific options (e.g. box cricket lets you set
  any number of players and choose tennis or leather ball).

If a format or street-rule variant you need isn't offered, tell us from
**Settings → Help & support**.

## Fix a mistake (Undo)

Everyone mis-taps. Every scoring action can be reversed.

- Tap **↶ Undo** to reverse the last action. Tap again to keep stepping back
  through the history — score, wicket, card, substitution, whatever it was.
- Undo restores the exact previous state, including the clock/innings, so the
  scoreboard is always correct.
- There's no penalty and nothing to confirm — undo freely while you find the
  right entry.

## Score offline & how syncing works

Matches happen on grounds with patchy signal. Sportfolio is built for that.

- Every tap is saved **on the device immediately** — you can score a whole match
  in airplane mode.
- When you're back online (and signed in on a live account), your scoring syncs
  up automatically. Nothing to press.
- Close the app mid-match by accident? Reopen it and the match is exactly where
  you left off.

*In demo mode there's no cloud sync — everything stays on the device, which is
why you can explore fully offline.*

## Rain, short matches & adjusted targets (cricket)

When weather or time cuts a cricket match short:

1. In the live scorer, tap **☔ Rain — reduce overs**.
2. Set the new number of overs.
3. The chasing side's **target recalculates automatically** — no manual maths at
   the ground.

The scoreboard clearly shows the revised overs and target so everyone knows
what's required.
