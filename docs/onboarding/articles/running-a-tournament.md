# Run a tournament, start to finish

*The full written companion to Episode 4. Publishes to the Help centre and the
blog. Maps to KB articles: `create-tournament`, `generate-fixtures`, `standings`.*

Running a tournament in Sportfolio takes four moves: **create it, add teams,
generate the fixtures, score the matches.** The standings and stat leaders keep
themselves from there. Here's the whole thing.

## 1. Create the tournament

Open the **Organize** tab and tap **🏆 New tournament**.

- **Name** — what it's called (e.g. "Karnataka State Cup 2026").
- **Host** — you personally, or a community (school, club, company) you run. When
  a community hosts, everyone in it can manage the tournament and gets reminders.
- **Dates** — start and end.
- **Sports** — pick one or more. A multi-sport meet keeps a separate table per
  sport, plus an overall cross-sport table.
- **Structure** — how the competition is shaped:
  - **League** — everyone plays everyone.
  - **Knockout** — single elimination; odd numbers get byes automatically.
  - **League + Knockout** — a group stage, then knockouts.
- **Knockout format** (only shown when there are knockouts) — how a level match is
  settled: **extra time then penalties**, or **straight to penalties**.
- **Format** — for each sport, pick a preset (T20, ODI, 7-a-side, Futsal, 3×3,
  and so on) or tap **Customize this format** to set the individual rules. Every
  match in the tournament then follows that format.
- **Registration** — **Open** (teams can find it in Discover and request to join)
  or **Invite only**.

Tap **Create tournament**. You land on the tournament hub.

## 2. Add teams

From the tournament (or **Organize → Manage teams**), add the teams taking part.
A player is identified by their phone number, so the same person is recognised
across every team and tournament.

## 3. Generate the fixtures

On the tournament, tap **⚡ Auto-generate fixtures**. Then:

- **Pick the teams** to include (or Select all).
- **Round-robin** (everyone plays everyone — once, or twice for home & away) or
  **Knockout** (a single-elimination round one, byes handled for odd numbers).
- Set a **start time** and a **gap** between matches, and an optional **venue**.
- Tap **Generate** to preview the pairings, then **Create** to make every match
  at once.

Prefer to schedule by hand? Use **Schedule a match** instead — auto-generate is
the optional shortcut, not the only way.

> Knockout fixtures inherit the tie-breaker you chose when creating the
> tournament, so a level knockout tie is settled the way you set it.

## 4. Score the matches

Open each match and score it like any other — tap to score, and finish. As
results come in:

- **Standings** update automatically. Open **📊 Standings & leaders** from the
  tournament. The top three teams are shown with 🥇🥈🥉; points are the hero
  column.
- **Stat leaders** (top scorers, and more, per sport) update alongside the table.
- For a multi-sport meet, there's an **overall** table across every sport, plus
  each sport's own.

## That's it

No spreadsheet, no manual maths, and nothing to lose if the wifi drops mid-match
(scoring works offline and syncs when you're back). If a format or rule you want
isn't offered yet, tell us from **Settings → Help & support** — we track those
requests.
