# Episode 6 — Choose a format (T20, 5-a-side, 3×3…)

- **Length:** ~75s
- **KB article:** `choose-format`
- **YouTube title:** Any format you play — T20, Futsal, 3×3 and more
- **Description:** Pick a format preset when you create a match or tournament, or
  customize every rule yourself. Plus how rain-reduced overs auto-adjust the
  target in cricket.
- **Thumbnail:** a row of format preset chips (T20 · Futsal · 3×3) with one selected.

| # | Visual (on screen) | Voiceover |
|---|--------------------|-----------|
| 1 | Creating a match; the format editor shows a row of preset chips for the sport. | The same sport is played a hundred ways. So when you set up a match or tournament, you pick the format. |
| 2 | Cricket presets: T20, ODI, T10, The Hundred, Sixes, Box, Test. Tap T20. | For cricket that's T20, ODI, The Hundred, box cricket — tap one and every rule is set at once. |
| 3 | Switch sport to football; presets: 11-a-side, 7s, 5s turf, Futsal. Tap Futsal. | Football? Eleven-a-side, sevens, five-a-side turf, futsal. |
| 4 | Switch to basketball; presets: 5v5, 3×3, 2v2, 1v1. Tap 3×3. | Basketball, right down to 3×3, 2v2, even 1v1. |
| 5 | Tap "⚙ Customize this format"; the individual rule fields appear (overs, players per side, periods…). | Want something in between? Tap Customize, and set the rules yourself — players per side, overs, periods. |
| 6 | Box-cricket path: show choosing the number of players and a "tennis ball / leather ball" toggle. | Box cricket doesn't have to be six-a-side — set any number — and choose tennis ball or leather. |
| 7 | Cut to a live cricket match; tap "☔ Rain — reduce overs", set fewer overs; the target updates. | And when rain cuts a match short, tap "Rain — reduce overs" and the target recalculates for you — no manual maths. |
| 8 | Cut to Sportfolio wordmark. | However you play it, Sportfolio scores it. |

**On-screen CTA (last 3s):** "Presets live in match & tournament setup"
