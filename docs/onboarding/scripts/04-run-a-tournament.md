# Episode 4 — Run a tournament, start to finish

- **Length:** ~3 min
- **KB articles:** `create-tournament`, `generate-fixtures`, `standings`
- **YouTube title:** Run a whole tournament on Sportfolio (full walkthrough)
- **Description:** From an empty screen to a live leaderboard — create a
  tournament, add teams, auto-generate the fixtures, score the matches, and watch
  the standings keep themselves. For school meets, club leagues, and street cups.
- **Thumbnail:** the standings board with gold/silver/bronze medals on the top three.

| # | Visual (on screen) | Voiceover |
|---|--------------------|-----------|
| 1 | Organize tab. Tap the green "🏆 New tournament". | Running a tournament sounds like a spreadsheet nightmare. It isn't. Let's build one end to end. Start on Organize — New tournament. |
| 2 | Type a name ("Karnataka State Cup"); pick the host (Myself). | Give it a name, and choose who's hosting — you, or a community you run. |
| 3 | Set start & end dates with the date pickers. | Set the dates. |
| 4 | Tap sport chips to select Football (and any others). | Pick the sports. A meet can run several at once — each gets its own table. |
| 5 | Tap Structure: show League, Knockout, League + Knockout; pick League + Knockout. | Choose the shape: a league where everyone plays everyone, a straight knockout, or a group stage then knockouts. |
| 6 | The knockout-format chips appear: "Extra time + Penalties" / "Direct Penalties". Pick one. | For knockouts, decide how a level match is settled — extra time and penalties, or straight to penalties. |
| 7 | Scroll to the per-sport format editor; show a preset (e.g. 7-a-side); tap "Customize" to reveal the details, then collapse. | Then the format. Pick a preset — like 7-a-side football or T20 cricket — or tap Customize to set every rule yourself. |
| 8 | Tap "Create tournament"; land on the tournament page. | Create it. There's your tournament hub. |
| 9 | Tap "👥 Manage teams"; add a few teams (Red House, Blue House, Green House, Gold House). | Add the teams taking part — from Manage teams. |
| 10 | Back on the tournament, tap "⚡ Auto-generate fixtures". | Now the part people dread — the fixtures. Tap Auto-generate. |
| 11 | On the fixtures screen: select all teams; pick Round-robin; set a start time and a gap; tap Generate; a list of matches appears. | Pick the teams, choose round-robin or knockout, set a start time and a gap between games — and it builds every pairing for you. Each team plays each other exactly once. |
| 12 | Tap Create; the matches appear under the tournament's Matches list. | Create them all at once. Done — your whole schedule, in seconds. |
| 13 | Open one match, score it to a result, end it. | Play the matches and score them like any other — tap to score, and finish. |
| 14 | Tap "📊 Standings & leaders"; the table shows, top three with 🥇🥈🥉. | And this is the payoff: the standings keep themselves. Every result updates the table — top three get the medals. |
| 15 | Scroll to the stat leaders (top scorers). | Plus your leaders — top scorers, and more, per sport. |
| 16 | Cut to Sportfolio wordmark. | That's a full tournament — no spreadsheet, no manual maths. Go run yours. |

**On-screen CTA (last 3s):** "Organize → New tournament"
